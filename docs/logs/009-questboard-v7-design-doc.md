# 009: QuestBoard設計書v7を作成

## 概要
v5/v6設計書と現在の実装状況を整理し、v7設計書としてまとめた。

## 変更内容

### 新規ファイル
- **`docs/資料系/questboard_v7.md`**: v7設計書

### v7で確定した事項
1. **認証方式**: 家族コード（6桁）＋ユーザーコード（4桁）のID/PW方式
2. **子どもアカウント作成**: 親側で実施（子どもはログインのみ）
3. **進化システム**: ステージ制＋ポイントリセット（10pt → 30pt → 70pt）
4. **XP値**: EASY=10, NORMAL=15, HARD=20
5. **モンスター名**: ユーザー名（表示名）として使用
6. **最終形態**: ステージ3が最終（v5/v6のLv15=150ptは省略）

### v7設計書の構成
- 確定事項サマリー（v6→v7の差分表）
- 認証・アカウント設計
- パラメータシステム（XP値確定）
- 進化システム（ステージ制の詳細仕様）
- タスク設計
- 実装状況一覧（実装済み/未実装）
- DBスキーマ（現在のPrismaスキーマを反映）
- 技術スタック
- βテスト設計
- 次の開発優先度

### v5/v6との主な差異
- レベル制 → ステージ制（ポイントリセット付き）
- XP値を大幅引き下げ（20/40/80 → 10/15/20）
- 子どものアカウント作成を親側に限定
- たまご(🥚)ステージは省略（初期からモンスター表示）
- パラメータ割合による進化分岐は未実装（将来課題）
