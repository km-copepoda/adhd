# 子ども画面をログインのみに変更

**日時:** 2026-03-11

## 指示
子どもの画面はログインするのみ。「はじめてのぼうけん」（新規キャラ作成フロー）は不要。

## 既存ログとの矛盾チェック
- logs/001: 初期設計では子ども=匿名認証+オンボーディング（名前→サイド→結果）あり → **今回で廃止**
- logs/003: 復帰フロー追加時に「コードなしではじめる」オプションあり → **今回で廃止**
- logs/004: 「ログインする」と「はじめてのぼうけん」の2択 → **今回で「ログインのみ」に変更**
- 矛盾なし（段階的に方針が変わっている。子どもの登録は親側で行う方針に統一）

## 修正内容

### 変更: `src/app/child/onboarding/page.tsx`
- **削除**: Welcome画面（ようこそ→ログイン/はじめてのぼうけん選択）
- **削除**: 新規キャラ作成フロー（name, side, result ステップ全て）
- **削除**: `handleComplete()` 関数（child-join API呼び出し）
- **削除**: `MONSTER_STAGES` import（不要になった）
- **変更**: 画面を1画面に簡素化 → ファミリーコード＋ユーザーコード入力のみ
- キャラクター（🥚）と「ようこそ、冒険者よ！」のメッセージは残してUXを維持
