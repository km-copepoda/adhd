# QuestBoard 利用マニュアル

QuestBoard は、おうちの人が出したタスク（クエスト）を子どもがこなし、報告と承認を通してモンスターを育てるアプリです。

## おうちの人向け

最初に「はじめに」を読んでください。そのあとは、やりたいことに合わせて各章を開いてください。

| 章 | 内容 |
|---|---|
| [はじめに](parent/getting-started.md) | 登録、子どもの追加、子どものログイン、ホーム画面への追加、通知、ナビの見方 |
| [タスク管理](parent/tasks.md) | タスクの作成・編集・停止、繰り返し・曜日・期限・写真、テンプレート、翌日に送る |
| [承認センター](parent/approve.md) | 報告の承認・差し戻し、スキップ申請への対応、まとめて承認、自動承認 |
| [宝箱とごほうび](parent/treasures.md) | 宝箱がもらえる条件、ごほうびの登録、使用申請への対応 |
| [モンスターの育成](parent/monster.md) | ポイントの種類、孵化・進化・転生、卵の選択 |
| [ストリーク・実績・コレクション](parent/streak-badges-collection.md) | 連続達成、ログインボーナス、実績（バッジ）、図鑑、コレクションアイテム |
| [子供モード](parent/child-view.md) | 子どもの画面を親が代わりに操作する |
| [ひろば](parent/gathering.md) | 合言葉でつながるグループ、掲示板、エール |
| [記録・履歴](parent/records.md) | 今日の達成、過去のカレンダー |
| [ファミリー設定とプラン](parent/family-and-plan.md) | 子どもごとの設定、子どもの削除、退会、無料プランとプレミアムプラン |

## こども向け

- [QuestBoard の つかいかた（こども よう）](child/index.md)

## 困ったとき

各章の最後に「よくある質問」があります。

| 困っていること | 見る場所 |
|---|---|
| 子どもがログインできない | [はじめに](parent/getting-started.md) |
| 通知が届かない | [はじめに](parent/getting-started.md) |
| XP（ポイント）が増えない | [承認センター](parent/approve.md) |
| 宝箱が開けられない・消えた | [宝箱とごほうび](parent/treasures.md) |
| タスクがこれ以上作れない | [ファミリー設定とプラン](parent/family-and-plan.md) |
| 進化しない | [モンスターの育成](parent/monster.md) |
