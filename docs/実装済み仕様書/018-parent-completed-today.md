# 018: 親画面に今日の完了タスク一覧ページを追加

**日時:** 2026-03-11

## 指示
今日完了したタスクを見れる画面が親の画面に欲しい。

## 既存ログとの矛盾チェック
- logs/001〜017: 「今日の完了タスク」表示機能は一度も実装されていない → 矛盾なし、純粋な新機能追加
- logs/001: `/parent/approve` は承認センター（REPORTED状態）として実装済み → 今回は別途APPROVED状態の一覧を表示
- logs/009(v7設計書): 実装優先度に「完了履歴」が未実装として記載あり → 今回で対応

## 変更内容

### 新規ファイル: `src/app/api/quests/completed-today/route.ts`
- GET: 今日（0時〜24時）に承認された（`status: "APPROVED"`、`approvedAt`が今日）クエスト一覧を返す
- 認証チェック: 親ユーザーのみ（`role !== "PARENT"`は空配列返却）
- ファミリーの子ども全員分を返す
- include: child（name, monsterName, side）, template（title, emoji, category, difficulty）
- orderBy: approvedAt降順

### 新規ファイル: `src/app/parent/completed/page.tsx`
- 今日承認済みタスクの一覧表示
- ヘッダーに件数と合計XP表示
- 各カードに: 絵文字・タスク名・子ども名・カテゴリ・XP・承認時刻・コメント
- 0件の場合は「今日はまだ完了したタスクがありません」表示

### 変更ファイル: `src/components/parent/Sidebar.tsx`
- `links` 配列に `{ href: "/parent/completed", emoji: "🏆", label: "今日の完了" }` を追加
- 承認（✅）とファミリー（👨‍👩‍👧‍👦）の間に配置
