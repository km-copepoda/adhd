# ファミリーコード + ユーザーコードによる子どもログイン

**日時:** 2026-03-11

## 問題
前回の復帰機能はファミリーコードだけでキャラ一覧を見せる方式だったが、
セキュリティ的にファミリーコード（=ID）＋ユーザーコード（=PW）の2要素で
ログインする仕組みが必要。

## 解決アプローチ
- 子どもごとに4桁のユーザーコード (`childCode`) を発行
- ファミリーコード + ユーザーコードの組み合わせで一意に子どもを特定
- ID/PW方式のログイン画面に変更

## 修正内容

### 変更: `prisma/schema.prisma`
- User モデルに `childCode String?` フィールド追加
- `@@unique([familyId, childCode])` 複合ユニーク制約追加（家族内で重複しないコード）

### 変更: `src/lib/constants.ts`
- `generateChildCode()` 関数追加（4桁の数字コード生成）

### 変更: `src/app/api/auth/child-join/route.ts`
- 新規キャラ作成時に `childCode` を自動生成・保存
- 家族内での重複を避けるリトライロジック（最大10回）

### 変更: `src/app/api/auth/child-rejoin/route.ts`
- 子ども一覧返却方式 → ファミリーコード + ユーザーコードでの直接認証方式に変更
- POSTのみ: `{ familyCode, childCode }` → 匿名セッション作成 → supabaseId紐付け

### 変更: `src/app/api/family/code/route.ts`
- メンバー情報に `childCode` を含めるように変更

### 変更: `src/app/parent/family/page.tsx`
- メンバー一覧に各子どものユーザーコードを表示
- 説明文を「ファミリーコード＋ユーザーコードでログイン」に変更

### 変更: `src/app/child/onboarding/page.tsx`
- Welcome画面を「ログインする」と「はじめてのぼうけん」の2択に変更
- ログイン画面: ファミリーコード（英数字6桁）＋ ユーザーコード（数字4桁）入力
- 新規作成画面: ファミリーコード入力欄を名前入力ステップに統合

## ログインフロー
```
Welcome
  ├─「ログインする」→ Login画面（ファミリーコード + ユーザーコード）→ /child/quests
  └─「はじめてのぼうけん」→ Name（+ファミリーコード任意）→ Side → Result → /child/quests
```

## テスト方法
1. 親アカウントでログイン → ファミリー管理 → ファミリーコードとユーザーコードを確認
2. 子どものデバイス/シークレットウィンドウで `/child/onboarding`
3. 「ログインする」→ ファミリーコード + ユーザーコード入力 → ログイン
4. クエスト画面に既存のキャラクターとして復帰
