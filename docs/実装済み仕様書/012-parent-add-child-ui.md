# 012: 親画面でのメンバー追加UI + 認証問題の調査

## 概要
親画面（ファミリー管理）に子どもアカウント追加フォームを実装。
併せてタスク作成不可・ファミリーコード非表示の原因を調査。

## 問題の調査結果

### タスク作成できない・ファミリーコードが出ない
- **原因**: Supabaseポート変更（54321→54331）に伴い、ブラウザの認証セッションが無効化
- `getCurrentUser()` が null を返すため、全APIが未認証として応答
- `/api/tasks` → 空配列 `[]`
- `/api/family/code` → `{code: null, members: []}`
- **解決策**: ブラウザで再ログイン（または新規登録）すれば復旧

### 親画面でメンバー追加できない
- **原因**: 子どもアカウント追加UIが存在しなかった
- v7設計書で「親側で子どもアカウントを作成」と確定していたが、UIが未実装だった

## 変更内容

### 新規ファイル
- **`src/app/api/family/members/route.ts`**: 子どもアカウント作成API
  - POST: 親がファミリーに子どもを追加
  - 名前（monsterName）とサイド（LIGHT/DARK）を受け取る
  - childCode（4桁）を自動生成（重複時リトライ付き）
  - supabaseIdはプレースホルダー（`pending_*`）で作成、子どもの初回ログイン時に更新

### 変更ファイル
- **`src/app/parent/family/page.tsx`**: メンバー追加フォームを追加
  - 「+ 子どもを追加」ボタン
  - 名前入力 + サイド選択（ライト🌸 / ダーク🌑）
  - 追加後にメンバーリスト再取得
  - エラーハンドリング付き
