# モンスターテーマセット仕様書

作成日: 2026-08-05

## 概要

進化ロジック（STUDY/STAMINA/LIFE の3パス × 3ステージ）はそのままに、モンスターの **見た目（名前・画像・説明文）をセットごと丸ごと差し替える** 買い切りコンテンツ。

- 1セット = 卵1 + 39体（Stage1×3 + Stage2×9 + Stage3×27）
- 価格帯: 各 300円程度（App Store Tier 2）
- デフォルト（dark/light）は無料。以下11セットは有料

### デザイン方針

- **性別で分けない** — テーマ選択 = 好みの表現であり、性別の表現ではない
- 各セットの Stage 1 はかわいく（男女問わず刺さる入口）、Stage 3 は迫力ある最終形態に
- 3軸（STUDY=知/STAMINA=力/LIFE=命）が見た目・性格に自然に反映されるデザイン

```ts
export const MONSTER_TABLE_DRAGON: Record<string, { image: string; name: string; description: string }> = {
  "STUDY": { image: "/monsters/dragon/STUDY_ウィルム.webp", name: "ウィルム", description: "..." },

};
```

### 画像パス規約

```
/monsters/{setId}/{PATH}_{名前}.webp
/monsters/{setId}/egg.webp
```

例: `/monsters/dragon/STUDY_STUDY_LIFE_セレナード.webp`
