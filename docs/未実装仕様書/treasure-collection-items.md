# 宝箱コレクションアイテム 仕様書

作成日: 2026-05-29

## 概要

宝箱のハズレ枠を「何も出ない」から「コレクションアイテムが出る」に変更する。
ADHD特性（拒絶感受性・可変報酬への反応）を踏まえ、「開けたら必ず何か手に入る」体験にする。

---

## 1. 抽選フロー

```
宝箱を開ける
  → ごほうび抽選（現状ロジック: drawTreasure そのまま）
    → 当たり → 親が設定したごほうびを出す
    → ハズレ → コレクション再抽選（必ず何か出る）
                → COMMON 60% / UNCOMMON 30% / RARE 10%
```

- ごほうび抽選ロジック（`src/lib/treasure.ts` の `drawTreasure`）は変更しない
- ハズレ時に追加でコレクション抽選を走らせる
- 天井（pity）はごほうび側にのみ残す（コレクションは必ず出るので不要）
- ダブりOK（同じアイテムが複数回出る。入手回数をカウントしてもよい）

---

## 2. シーズン制

### 仕組み

- コレクションアイテムは**季節ごとに20種**を用意し、3ヶ月単位でローテーションする
- 現在の季節のアイテムのみ抽選対象になる
- 季節が変わると前シーズンのアイテムは入手不可になる（所持済みのものは残る）

### シーズン期間

| シーズン | 期間 |
|---------|------|
| 春（はる） | 3月〜5月 |
| 夏（なつ） | 6月〜8月 |
| 秋（あき） | 9月〜11月 |
| 冬（ふゆ） | 12月〜2月 |

### 狙い

- 常時20種しか出ないため**レア感を維持**できる
- 3ヶ月ごとの全入れ替えで**飽きを防止**
- 「この季節のうちにコンプしたい」という**期限つきの動機**が生まれる（ADHDは締切がある方が動ける）
- 過去シーズンのアイテムを持っている子が**自慢できる**（所有感）

---

| レア度 | 各シーズンの種類数 | コレクション抽選時の出現率 |

## 5. 運用方針

- 季節の切り替えは月初（3/1, 6/1, 9/1, 12/1）に自動で行う
- 切り替え時の告知は不要（自然に入れ替わる体験の方がADHD的に負担が少ない）
- 2年目以降は同じアイテムが再登場してよい（去年取れなかったものを今年取れる）
- コレクション画面から外部リンクや動的コンテンツへの導線は作らない（スクリーンタイム対策）

---

## 6. 実装時の注意

- コレクションアイテムのマスターデータは `src/lib/` に定数として定義する（DB管理ではなくコード管理）
- シーズン判定は `src/lib/date.ts` のJST基準の日付関数を使う
- コレクション抽選は `src/lib/treasure.ts` に追加するか、別ファイル `src/lib/collectionDraw.ts` に分離する
- 子供の所持アイテムはDBに保存する（アイテムID + 入手回数 + 入手日）
- コレクション一覧画面では現在の季節タブをデフォルト表示し、過去シーズンも閲覧可能にする
