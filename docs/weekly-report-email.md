# 親向け週次レポートメール 仕様書

作成日: 2026-05-29

## 目的

子供の継続率を上げるため、親に週次レポートをメールで送信する。
親がリアルの会話で「がんばったね」と褒めるきっかけを作ることが最大の狙い。

---

## 1. 配信概要

| 項目 | 内容 |
|------|------|
| 配信手段 | メール（Resend + React Email） |
| 配信タイミング | **毎週月曜 朝7:00（JST）** |
| 集計期間 | 前週の月曜 0:00 〜 日曜 23:59（JST） |
| 複数子供 | 1通にまとめる（子供ごとにセクション分け） |
| 送信先 | 親アカウントの登録メールアドレス |

### 月曜朝にした理由

- 日曜分の承認が完了している可能性が高い
- 「新しい週の始まり」で意識が高まるタイミング
- 集計期間が完全な1週間になる

### 参考: 他サービスの配信タイミング

| サービス | 配信日 | 集計期間 | 特徴 |
|---------|--------|---------|------|
| Duolingo | **金曜 14時頃** | 日〜金（途中結果） | 週末前に送り「あと2日がんばろう」を促す。学習者本人向け |
| Fitbit | 日曜深夜〜月曜朝 | 月〜日 | 完全な1週間の振り返り |

Duolingoは週の途中で送ることで行動を促すアプローチだが、本アプリは「親に褒めてもらうきっかけ」が目的のため、結果が確定した月曜朝が適切と判断した。

## 2. メール内容

### 件名

`📊 {子供の名前}の今週のレポート`（複数子供の場合: `📊 今週のレポート`）

### 本文（子供1人あたり）

```
🐣 {モンスター名 or 子供の名前}の先週のレポート

✅ {N}日達成（先週より {+N / -N / ±0}日）
🔥 ストリーク {N}日継続中
⚔️ クエスト {N}個完了

{一言コメント}
```

### 一言コメントのロジック

| 条件 | コメント |
|------|---------|
| 先週より達成日数が増えた | がんばってるね！ほめてあげてね 😊 |
| 7日全部達成 | パーフェクト！すごい1週間だったね 🎉 |
| 先週と同じ | 安定してがんばってるね！ |
| 先週より減った | ペースダウンしたけど大丈夫。声をかけてあげてね |
| 0日だった | 今週はおやすみだったみたい。無理せず再開できるといいね |
| 初週（比較データなし） | はじめての1週間！見守ってあげてね 😊 |

### トーン

- 親向けなので子供画面より少し落ち着いたトーン
- ただし堅すぎない（「です/ます」は使うが事務的にはしない）
- **子供を責めるような表現は絶対にしない**
- 「褒めてあげてね」「声をかけてあげてね」で親のアクションを促す

## 3. 声かけヒント（褒め方Tips）

メール末尾に、子供の状況に合わせた声かけヒントを1つ添える。
ペアレントトレーニングのエビデンスに基づいた内容。

### 表示例

```
💡 今週の声かけヒント

「5日もできたね！」より
「自分からタブレット開いてやれたね」

→ どの行動が良かったかを伝えると
  子供が「次もやろう」と思いやすくなります
```

### Tips一覧（8種）

| # | テーマ | メール表示文 | エビデンス根拠（メールには表示しない） |
|---|--------|-------------|--------------------------------------|
| 1 | 行動を名指しで褒める | 「がんばったね」より「自分からタブレット開いてやれたね」。**どの行動が良かったか**を伝えると再現しやすくなります | Labeled Praise（行動特定の褒め）。50年以上の研究で効果実証 |
| 2 | すぐ声をかける | レポートを見たら**その日のうちに**褒めてあげてください。時間が経つと結びつきが薄れます | 即時強化の原則。ADHD児はワーキングメモリの特性上、遅延報酬の効果が弱い |
| 3 | 「着手」を褒める | 「全部できた」より「始められた」ことがすごい。ADHDの子にとって最も難しいのは**やり始めること**です | 実行機能障害の中核。着手困難はADHDの主症状 |
| 4 | 当たり前も褒める | 毎日やってることでも「今日もちゃんとできたね」と伝える。習慣になった行動も褒め続けることで定着します | ペアレントトレーニングの基本。「当然」を褒めることで自信がつく |
| 5 | 比べるのは過去の本人だけ | 「先週は3日、今週は5日」のように**本人の変化**を伝える。きょうだいや他の子との比較は自己肯定感を下げます | ペアレントトレーニングで明確に禁止される声かけパターン |
| 6 | 休んでも大丈夫と伝える | ストリークが切れても「また始められたのがえらい」。休んだことを責めると戻れなくなります | 回避行動の強化防止。罰的対応はADHD児に逆効果 |
| 7 | 「見てるよ」を伝える | 「がんばったね」に加えて「ちゃんと見てるよ」。ADHDの子は**気づいてもらえていない**と感じやすいです | RSD（拒絶感受性）。ADHD児に多い情緒的特性 |
| 8 | 「できない」と言えたことを認める | スキップは悪いことじゃなく**自己理解の一歩**。「自分で判断できたね」と伝えてあげてください | メタ認知の発達を強化。自己モニタリング能力はADHDの改善指標 |

### 出し分けロジック

子供の状況に合わせて選択する（ランダムではない）：

| 子供の状況 | 出すTips |
|-----------|---------|
| 先週より達成日数が増えた | #1 行動を名指しで褒める |
| パーフェクト週（7日達成） | #4 当たり前も褒める |
| 先週と同じ | #7 「見てるよ」を伝える |
| 先週より減った | #6 休んでも大丈夫と伝える |
| 0日だった | #6 休んでも大丈夫と伝える |
| スキップが多い週 | #8 「できない」と言えたことを認める |
| 初週 | #2 すぐ声をかける |
| 2回目以降で上記に該当しない | #3 → #5 → #7 の順にローテーション |

## 4. 配信条件

| 条件 | 配信する？ |
|------|-----------|
| 子供がいない親アカウント | しない |
| 子供が先週0日だった | **する**（離脱検知の意味もある） |
| 親がメール未登録 | しない |
| 親が配信停止した | しない |

### 配信停止

- メール末尾に「配信停止」リンクを設置
- DB に `weeklyReportOptOut: Boolean` フラグを持たせる

## 5. 技術構成

### メール送信

| 項目 | 選定 |
|------|------|
| メールサービス | Resend（無料枠: 月3,000通） |
| テンプレート | React Email（TSXでメール作成） |
| 配信トリガー | Vercel Cron（`cron: "0 22 * * 0"` = UTC日曜22時 = JST月曜7時） |

### 集計に必要なデータ

- `QuestInstance`: 対象期間内の status=APPROVED のカウント（達成日数・クエスト数）
- `User`: currentStreak（ストリーク）
- `User`: monsterName（レポート表示名）
- 先週分のデータ: 前々週の同じ集計を行い比較

---

## 6. 実装時の注意

- Resend APIキーは環境変数 `RESEND_API_KEY` に設定
- Vercel Marketplace から Resend を統合する
- メールテンプレートは `src/emails/` ディレクトリに配置（React Email の慣習）
- Cron ジョブは `src/app/api/cron/weekly-report/route.ts` に配置
- Cron のセキュリティ: `CRON_SECRET` で認証する（Vercel Cron の標準パターン）
- 初回導入時は自分のアカウントでテスト送信してからリリース
