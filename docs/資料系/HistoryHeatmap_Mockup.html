📋 変更差分メモ

要素 Before After
カレンダーセル 数字のみ、全日同じ見た目 達成度で色分け（金=全完了, 緑系=一部, 橙=スキップ, グレー=未達成）
月次サマリー なし 追加 達成日数 / 完了タスク数 / 獲得XP の3カード
子供フィルター なし 追加 複数の子供がいる場合に「全員/個人」で絞り込み
※子供が1人のみのファミリーは表示しない
新API なし GET /api/quests/monthly-summary?year=2026&month=4&childId=xxx NEW
戻り値: { "2026-04-01": { approved:2, skipped:0, noAction:1 }, ... }
QuestInstanceをmonth全体でGROUP BY date で集計。月初に1回フェッチ。
既存API変更 GET /api/quests/history?date= は変更なし。日付クリック時の詳細取得に引き続き使用。
色判定ロジック なし getHeatLevel(approved, skipped, noAction) NEW
noAction=0かつskipped=0 → 金（完璧）
noAction=0かつskipped>0 → 橙（スキップあり）
approved>0 → 緑（一部〜ほぼ完了）
approved=0 → グレー（未達成）
