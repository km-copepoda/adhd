# 実績（バッジ）機能 廃止仕様書

作成日: 2026-05-29

## 廃止理由

- 子供が実績を意識してタスクに取り組む行動が観測されていない
- 「この実績が出たよ！」という親子の会話もほぼ発生していない
- 100個のバッジの大半が「N回やった」の累計カウンターであり、子供が能動的に狙う設計になっていない
- emojiアイコンのみでビジュアルのインパクトが薄く、所有感がない
- モンスター育成（専用ドット絵・進化演出）が既に動機づけとして機能しているため、役割が重複している

---

## 廃止範囲

### 子供画面

- バッジページ（`/app/child/badges`）を削除
- BottomNav からバッジタブを削除
- バッジ解除通知（`BadgeUnlockToast`）を削除
- ストリークマイルストーン通知も廃止を検討

### ロジック

- `src/lib/badges.data.ts` — バッジ定義・条件チェック（100個）
- `src/lib/badges.ts` — DB操作（バッジ解除処理）
- `src/components/child/BadgeUnlockToast.tsx` — 解除演出
- `src/components/child/AchievementBell.tsx` — 通知ベル
- 承認処理（`src/lib/approve.ts`）内のバッジチェック呼び出し

### API

- `/api/badges/unseen-count` — 未読バッジ数
- その他バッジ関連エンドポイント

---

## 残すもの

- 累計データ（クエスト完了数、ストリーク、XP等）は**親向けダッシュボード**で引き続き閲覧可能にする
- DB の `UserBadge` テーブルはすぐには削除せず、マイグレーションで後日対応
- ストリーク計算ロジック自体は進化・XP計算で使用しているため残す

---

## 代替

実績が担っていた「コレクションする楽しさ」は、宝箱コレクションアイテム（`docs/treasure-collection-items.md` 参照）に置き換える。
